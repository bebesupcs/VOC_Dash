## 🧭 1. 대시보드 구조 및 데이터 파이프라인

고객센터로 유입되는 **모든 고객의 소리(VOC)**를 4대 채널에서 자동 수집하여, **"어떤 문제가 발생했고, 누가 어떻게 응대했으며, 어디서 지연되는가?"**를 실시간 분석하는 시스템입니다.

```
[전화 CTI 원장] ──┐
[채널톡 채팅]   ──┼──▶ [통합 데이터베이스] ──▶ [VOC 종합 대시보드]
[배송 물류원장] ──┤                                 │
[쇼핑몰 게시판] ──┘                                 ▼
                                      • 품질 / 배송 / 서비스 3대 클레임 분류
                                      • 상담사별 전화+채팅 종합 실적 매트릭스
                                      • AI 챗봇(ALF) 자동 처리율 모니터링
                                      • 클레임 해결 리드타임 & 병목 4사분면
```

## 💡 2. 주요 기능(Feature) 200% 활용법

대시보드에 탑재된 주요 기능들을 실무에서 어떻게 다루는지 설명합니다.

### ① 동적 연도 및 기간 컨트롤러 (신규 탑재)
* **연도 콤보박스**: `2025년`, `2026년`을 선택하면 하단 주차 드롭다운이 해당 연도의 데이터만 정렬되어 스크롤 낭비가 없습니다. (2027년이 되면 시스템이 자동 감지하여 추가됨)
* **⚡ 현재로 가기 버튼**: 과거 주차나 다른 연도를 보다가 언제든 클릭 한 번으로 **가장 최신 주차**로 즉시 돌아옵니다.
* **주간 / 월간 / 분기 / 연간 모드 전환**: 상단 버튼 클릭 시 전체 통계 기준(주차별, 달력 1일~말일, 분기별)이 자동으로 재집계됩니다.

### ② 단일 이슈 필터 (FCR 품질 보정)
* **동작 원리**: 48시간 이내 동일 고객이 여러 번 문의한 건(재통화/재인입)을 제외하고, **순수 발생 이슈 건수**만 필터링합니다.
* **활용법**: 실제 제품에 발생한 '고유 결함 모수'를 파악할 때 켜두면 데이터 왜곡을 방지할 수 있습니다.

### ③ 4사분면 리스크 매트릭스 인터랙션
* **버블 클릭 / 호버**: 각 세부 태그에 마우스를 올리면 `평균 해결시간(시간/일)`과 `재통화 횟수` 툴팁이 뜹니다.
* **사분면 필터 버튼(Q1~Q4)**: 상단 필터 칩을 누르면 우측 상세 테이블이 해당 사분면에 속한 불만 유형만 즉시 필터링됩니다.

### ④ 원클릭 종합 엑셀 리포트 다운로드
* 상단의 `[리포트 다운로드]` 버튼을 누르면 화면의 통계 차트뿐 아니라, **품질 원장, 신규 배송 원장, 사진 증빙 및 보상 내역서**까지 포함된 공식 Excel 보고서가 자동 패키징되어 저장됩니다.

## 📊 3. 핵심 지표 해석 공식 및 기준선 (Benchmark)

지표 수치를 볼 때 **"이게 좋은 수치인가, 위험한 수치인가?"**를 판단하는 공식 기준입니다.

| 핵심 지표 | 산출 기준 | 적정 기준치 (Healthy) | 경고/위험 기준 (Action Required) |
| :--- | :--- | :--- | :--- |
| **FCR (1회 종결율)** | 최초 1회 통화/채팅만으로 종결된 건수 비율 | **80% 이상** | **70% 미만** (동일 문제로 고객이 다시 전화하고 있음) |
| **평균 해결 리드타임** | 최초 인입 시점부터 최종 종결/통화 완료까지 소요 시간 | **24시간 이내 (당일)** | **48시간 (2일) 초과** (회수 지연, 공장 검수 병목) |
| **CTI 전화 응대율** | 상담원 연결 대상 통화 중 실제 연결된 비율 | **95% 이상** | **90% 미만** (콜 포기호 발생, 대기열 과부하) |
| **ALF 자체완결율** | 챗봇 인입 건 중 상담원 이관 없이 AI가 끝낸 비율 | **25% ~ 35%** | **15% 미만** (시나리오 미흡) / **50% 초과** (고객 피로도 점검) |
| **48시간 이내 재인입율** | 1차 통화 후 48시간 이내 동일 고객 재문의 비율 | **10% 이하** | **15% 초과** (1차 상담 시 안내 불충분 또는 약속 미이행) |

## 🔍 4. 실무자를 위한 4대 액션 인사이트 도출 가이드

대시보드 데이터를 보고 **유관부서와 실제로 어떻게 협업하고 액션을 취해야 하는지**에 대한 실무 가이드입니다.

```
┌────────────────────────────────────────────────────────┐
│                   VOC 인사이트 의사결정 흐름            │
├─────────────────┬──────────────────────────────────────┤
│ 1. 이상 감지    │ 주간 변동률(▲/▼), 고위험 뱃지 모니터링  │
│ 2. 원인 심층 분석│ 4사분면 위치, 벤더 구분, 제조일자 확인  │
│ 3. 부서별 조치  │ SCM(물류), 품질(공장), CX(매뉴얼) 협업  │
│ 4. 사후 피드백  │ 차주 FCR 회복 및 리드타임 단축 검증   │
└─────────────────┴──────────────────────────────────────┘
```

### 1) 🧪 품질 클레임 인사이트 ➔ [품질관리팀 / 제조공장 협업]
* **체크 포인트**:
  1. `이물질`, `냄새(이취)`, `변질(곰팡이)` 등 **고위험(HIGH) 클레임** 발생 건수 모니터링.
  2. 우측 상세 테이블에서 **제조일자(Lot 번호)**별 불량 집중 여부 확인.
* **실무 액션**:
  * 특정 제조일자에서 동일 불만이 3건 이상 집중 발생 시, 해당 로트 생산 라인의 원단 롤(Roll) 검수 일지 즉시 요청.
  * 회수 제품 사진 증빙을 대시보드에서 확인 후 연구소/품질팀에 성분 분석 의뢰 및 고객 안심 케어(맞교환/보상) 신속 집행.

### 2) 🚚 배송 클레임 인사이트 ➔ [SCM / 물류 벤더사 협업]
* **체크 포인트**:
  1. **초저온(CJ) vs 풀필먼트** 간의 클레임 점유율 및 파손율 비교.
  2. 유형 순위 차트에서 `파손반송`, `박스파손`, `배송지연` 비중 확인.
* **실무 액션**:
  * **박스 파손 급증 시**: 특정 택배사/물류 센터의 간선 상하차 충격 의심 ➔ 완충재(에어캡) 보강 또는 물류센터 현장 패킹 프로세스 점검 요청.
  * **배송지연 급증 시**: 기상 악화 또는 특정 지역 터미널 병목 여부 추적 ➔ 배송 지연 고객 대상 알림톡 선제 발송.

### 3) 🗺️ 리드타임 & 4사분면 인사이트 ➔ [고질적 병목 해결]
4사분면 차트는 `해결 리드타임(가로축)`과 `재통화 발생률(세로축)`을 교차 분석합니다.

```
               [재통화율 HIGH]
                      │
     [2사분면: 안내 보강]   │   [1사분면: 최우선 해결 대상!]
     • 재통화는 잦으나        │   • 리드타임도 길고 재통화도 폭발
     • 리드타임은 짧음       │   • 약품 냄새, 원단 이물, 강성 불만
     • 단순 배송지연, 미수취   │   ➔ VIP 전담 케어 / 선출고 필수
──────────────────────┼──────────────────────▶ [리드타임 LONG]
     [3사분면: 이상적 해결] │   [4사분면: 절차 간소화 대상]
     • 1회 통화로 당일 해결   │   • 재통화는 없으나 처리 지연
     • 단순 반품, 파손 맞교환 │   • 택배사 분실 보상 승인 대기
                      │   ➔ 승인 전결권 하향 조정 필요
               [재통화율 LOW]
```
* **1사분면(적색 리스크)**: 고객이 3~4번씩 전화하고 해결에 4일 이상 걸리는 최악의 구간입니다. 이 유형은 상담사 재량으로 **선출고 맞교환을 즉시 허용**하여 리드타임을 하루로 줄여야 합니다.
* **4사분면(지연 구간)**: 고객은 조용히 기다리는데 내부 처리 절차(택배사 보상 승인 등) 때문에 늦어지는 구간입니다. **보상 처리 전결권**을 완화하여 처리 속도를 높입니다.

### 4) 👥 상담 운영 & 인력 배치 인사이트 ➔ [CX 파트장 / 관리자]
* **시간대별 인입 흐름(`channelHourChart`) 활용**:
  * 10시~11시(오전 피크)와 14시~15시(점심 직후 피크)에 콜이 집중되는지 점검 ➔ 해당 시간대 상담사 집중 대기 편성 및 내부 회의 지양.
* **상담사별 실적 매트릭스 활용**:
  * 전화 대비 채팅 응대 비중이 한쪽으로 치우쳐 있는지 확인하여 업무 분장 균형 유지.
  * 특정 상담원의 재통화율이 유독 높다면 상담 스킬이나 첫 통화 설명 스크립트 피드백 진행.

## 🚀 5. 매주 정기 업데이트 방법 (딱 3단계)

### Step 1. 평소처럼 엑셀 파일 저장
* 공유 드라이브(`X:\...`) 또는 지정 폴더에 이번 주 채널톡, CTI, 배송사 원장 엑셀을 저장합니다.

### Step 2. 대시보드에서 `[데이터 원클릭 최신화]` 버튼 클릭
1. 대시보드 상단의 **`⚡ 데이터 원클릭 최신화`** 버튼을 클릭합니다.
2. 약 5~10초간 자동으로 새 데이터를 읽어 들이고 집계합니다.
3. 완료되면 **"✨ 채널톡·배송·게시판 최신 데이터 패치 완료!"** 메시지가 뜹니다.

### Step 3. 브라우저에서 `Ctrl + F5` 누르기
* 브라우저 캐시를 지우고 최신 데이터를 화면에 띄웁니다.

## ❓ 6. 자주 묻는 질문 (FAQ)

### Q1. 데이터를 업데이트했는데 화면 숫자가 안 바뀌어요!
> **답변**: 브라우저 캐시 때문입니다. 키보드의 **`Ctrl + F5` (강력 새로고침)**를 누르시면 즉시 최신 데이터가 반영됩니다.

### Q2. 2027년이 되면 시스템을 수정해야 하나요?
> **답변**: **전혀 필요 없습니다.**  
> 상단 연도 드롭다운은 데이터셋에 새 연도 데이터가 들어오는 즉시 스스로 감지하여 2027년을 목록에 띄워줍니다.

### Q3. 상담사 실적에서 채팅 건수가 0건으로 잡히면 어떻게 하나요?
> **답변**: 채널톡 엑셀에서 상담사 ID가 누락되었을 때 발생하며, 백엔드 자동 보정 스크립트(`scripts/apply_counselor_fix.py`)가 준비되어 있어 즉각 복구 가능합니다.
