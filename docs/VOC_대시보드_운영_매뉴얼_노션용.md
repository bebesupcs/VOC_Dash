## 🧭 1. 대시보드 한눈에 이해하기

### 💡 이 대시보드는 무엇인가요?
고객센터로 들어오는 **모든 고객의 소리(VOC)**를 한곳에 모아, **"지금 우리 제품과 배송, 서비스에 어떤 문제가 있고 누가 얼마나 응대하고 있는가?"**를 실시간으로 분석해주는 종합 관제탑입니다.

```
[전화 CTI]    ─┐
[채널톡 채팅]  ─┼──▶ [통합 데이터베이스] ──▶ [VOC 종합 대시보드]
[배송사 원장]  ─┤                                 │
[쇼핑몰 게시판]─┘                                 ▼
                                      • 품질 / 배송 / 서비스 클레임 추적
                                      • 상담사별 전화+채팅 종합 실적
                                      • AI 챗봇(ALF) 자동 처리율
                                      • 클레임 해결 리드타임 & 병목 구간
```

### 📊 4대 인입 채널 구분
1. **전화 (Call / CTI)**: 유선 전화로 고객이 건 전화(수신/IN) 및 상담사가 다시 건 전화(발신/OUT).
2. **상담사챗 (Agent Chat)**: 채널톡 채팅창에서 실제 상담사가 고객과 1:1로 직접 대화한 건.
3. **챗봇 (ALF)**: 인공지능 챗봇이 고객을 맞이하여 상담사 연결 없이 스스로 해결한 건.
4. **게시판 (Q&A)**: 네이버 스마트스토어, 자사몰 등에 고객이 수기로 남긴 문의 글.

## 🖥️ 2. 핵심 화면 및 지표 읽는 법 (비전공자용)

### ① 상단 분석 기간 & 연도 설정
* **모드 선택**: `주간` / `월간` / `분기` / `연간` 단위로 보고서를 자유롭게 전환합니다.
* **연도 필터**: `2025년`, `2026년` 등 원하는 연도를 선택하면 해당 연도의 주차만 깔끔하게 나옵니다.
* **⚡ 현재로 가기**: 과거 데이터를 보다가 언제든 클릭 한 번으로 **가장 최신 주차**로 바로 돌아옵니다.

---

### ② 3대 핵심 클레임 영역
대시보드 상단의 3대 카드는 고객 불만을 성격별로 분류한 것입니다.

| 클레임 구분 | 어떤 내용인가요? | 주요 모니터링 포인트 |
| :--- | :--- | :--- |
| **🧪 품질 클레임** | 물티슈 이물질, 냄새(이취), 곰팡이, 캡 파손 등 **제조/원단 불만** | 변질/이물 등 고위험 클레임 추이, 제조일자별 불량률 |
| **🚚 배송 클레임** | 택배 박스 파손, 배송 지연, 오배송, 분실 등 **물류사 배송 문제** | **초저온** vs **풀필먼트** 벤더별 파손율 및 지연 건수 |
| **💬 서비스 클레임** | 상담 태도, 지연 안내, 환불 처리 누락 등 **CS 응대 과정 문제** | 상담사 휴먼에러 여부, 에스컬레이션(관리자 이관) 건수 |

---

### ③ 상담사별 종합 실적 매트릭스
* **전화(CTI 통화)**: 상담원이 실제 통화 완료한 수신(인바운드)과 발신(아웃바운드) 건수.
* **채팅(상담사 응대)**: 채널톡 채팅 중 상담사가 직접 상담을 인계받아 해결한 건수.
* **최종 실적 합계**: 전화 + 채팅을 합산하여 **상담사 한 명이 처리한 전체 업무량**을 객관적으로 집계합니다.

---

### ④ 💬 채팅상담 & ALF (AI 챗봇) 분석
* **총 채팅 접수량**: 채팅창이 열린 전체 건수.
* **상담사 직접 응대**: 상담원에게 연결되어 사람이 처리한 비율 (예: 73%).
* **ALF (AI 상담)**: 챗봇이 인사말 및 FAQ 버튼 안내를 통해 상담사 없이 자체 완결한 비율 (예: 27%).

---

### ⑤ 🗺️ 클레임 해결 프로세스 여정 (Resolution Flow)
고객이 클레임을 제기했을 때 **얼마나 빨리 해결되는지**를 4단계 파이프라인으로 보여줍니다.
1. **STEP 1 (접수)**: 최초 클레임 접수 (100%).
2. **STEP 2-A (즉시 해결 / FCR)**: **추가 전화 없이 당일 1회 통화로 끝난 비율** (80% 이상이 우수 기준).
3. **STEP 2-B (재통화 발생)**: 2~3회 이상 다시 전화를 주고받은 비율 (지연 위험군).
4. **STEP 3 (고위험 장기군)**: 4회 이상 통화가 오가며 공장 검수/성분 분석 등이 들어간 장기 미결군.

## 🚀 3. 매주 정기 업데이트 방법 (딱 3단계)

새로운 주차 데이터가 추가되었을 때 관리자가 수행하는 방법입니다.

### Step 1. 평소처럼 데이터 업로드
* 공유 드라이브(`X:\...`) 또는 지정 폴더에 이번 주 채널톡 엑셀, CTI 엑셀, 배송사 원장을 평소대로 저장합니다.

### Step 2. 대시보드에서 `[데이터 원클릭 최신화]` 버튼 클릭
1. 대시보드 화면 상단(또는 좌측)에 있는 **`⚡ 데이터 원클릭 최신화`** 버튼을 클릭합니다.
2. 약 5~10초간 자동으로 새 데이터를 읽어 들이고 집계합니다.
3. 완료되면 **"✨ 채널톡·배송·게시판 최신 데이터 패치 완료!"** 메시지가 뜹니다.

### Step 3. 브라우저에서 `Ctrl + F5` 누르기
* 브라우저에 남아있던 예전 임시 데이터를 지우고 새 데이터를 깨끗하게 불러옵니다. 끝!

## ❓ 4. 자주 묻는 질문 (FAQ & 트러블슈팅)

### Q1. 데이터를 업데이트했는데 화면 숫자가 그대로예요!
> **해결책**: 브라우저 캐시(임시 기억 장치) 때문입니다. 키보드의 **`Ctrl` 키를 누른 상태에서 `F5`**를 눌러주시면 즉시 최신 데이터가 반영됩니다.

### Q2. 상담사 실적에서 채팅 건수가 0건으로 나와요!
> **원인**: 채널톡 원본 데이터 추출 시 상담사 고유번호(`assigneeId`) 매핑이 누락되었을 때 발생합니다.  
> **해결책**: 백엔드 복구 스크립트(`scripts/apply_counselor_fix.py`)가 준비되어 있으므로, 1회 실행해주시면 DB 원장과 자동 동기화되어 즉시 정상화됩니다.

### Q3. 내년(2027년)이 되면 코드를 또 고쳐야 하나요?
> **답변**: **아닙니다!**  
> 이번에 업데이트된 `A안(동적 연도 드롭다운)` 방식에 따라, 2027년 데이터가 파일에 한 줄이라도 들어오면 **대시보드가 스스로 2027년을 감지하여 드롭다운에 자동으로 띄워줍니다.** 수동 수정이 일체 필요 없습니다.

### Q4. 배송 클레임에서 '초저온'과 '풀필먼트'는 무엇인가요?
> * **초저온**: 냉장/냉동 전용 보관 및 배송 물류사(CJ대한통운 초저온 센터)를 의미합니다.
> * **풀필먼트**: 상온 보관 및 일반 택배 출고를 담당하는 물류 센터입니다.
